# v2 Prep

Working files for the v2 individual-level analysis (multilevel regression using RTM microdata). None of these are needed to reproduce the v1.0 paper or its figures.

This directory is excluded from git via `.gitignore`. Readers of the public repository will not see it. The files are kept locally to preserve work in progress: RTM codebook extractions, variable harmonization audits, DV factor analysis, and earlier pipeline scripts that depend on RTM microdata access.
